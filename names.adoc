= Name Analysis
Bubs | {docdatetime}

<<name_table>> describes the acceptability for names given the following key: 

* `Y` = The name is very acceptable. The name can be used in every day conversation without a cringe factor, sense of regret, or negative association.
* `N` = The name is not acceptable and should be disregarded because of cringe factor, sense of regret, or negative association. 
* `X` = The name was marked as a `Y` by Bubs but was not liked and removed from the list by Noodle.
* `Z` = The name needs more deliberation and careful consideration for about 20 minutes, which includes a session of conversion with the name and Noodle saying the name back to bubs. 



NOTE: Some first names are also marked as middle name contenders. This does not mean that all first names that are liked are acceptable as middle names because of the way they sound.
